# Реализация вертикального среза

## Игровой поток

1. Игрок просыпается в центре управления.
2. В первом акте исследует камеру, столовую и медпункт.
3. После трёх находок открывается гермодверь технического отсека Б-3.
4. Во втором акте игрок находит сообщение дочери, неисправный клапан и черновик рапорта.
5. В третьем акте столовая превращается в психологический «суд».
6. После суда открывается путь к антенному модулю.
7. Игрок выбирает признание или вытеснение.

## Архитектура

- `index.html` — UI-слои, HUD и игровые панели;
- `styles.css` — визуальный стиль терминала и экранные эффекты;
- `src/js/main.js` — игровой цикл, raycasting, AI проекций, сюжет и WebAudio;
- `scripts/build.mjs` — сборка статического каталога `dist`;
- `scripts/serve.mjs` — локальный сервер без зависимостей;
- `.github/workflows/deploy-pages.yml` — CI/CD для GitHub Pages.

## Возможное развитие

- перенос логики в Three.js, Godot, Unity или Unreal Engine;
- полноценные 3D-модели станции и экипажа;
- локализация и профессиональная озвучка;
- система сохранений по главам;
- дополнительные каюты и истории всех одиннадцати членов экипажа;
- пространственный звук и поддержка геймпада;
- отдельный режим демонстрации для Steam Next Fest.
