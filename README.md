# Отдел утилизации: Долг

Играбельный браузерный вертикальный срез психологического хоррора от первого лица по дизайн-документу **«Отдел утилизации: Долг»**.

> «Вина — единственный монстр, от которого невозможно спрятаться».

## Что реализовано

- псевдо-3D станция с рендерингом от первого лица без внешних библиотек;
- управление WASD + мышь, фонарь, карта станции и интерактивные объекты;
- три акта: **«Пробуждение»**, **«Трещины»**, **«Долг»**;
- семь сюжетных фрагментов памяти;
- проекции погибших по механике «движутся, когда игрок не смотрит»;
- процедурный звук: гул станции, шаги, помехи и металлические импульсы;
- деградация света, палитры и пространства по мере восстановления памяти;
- финальный выбор и две концовки: **«Признание»** и **«Вытеснение»**;
- сохранение метки петли отрицания через `localStorage`;
- готовая сборка и автоматический деплой на GitHub Pages.

Это компактный вертикальный срез продолжительностью примерно 20–30 минут, а не полная 4–6-часовая версия из GDD.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` | движение |
| мышь | обзор |
| `Shift` | быстрый шаг |
| `E` | взаимодействие / закрыть запись |
| `F` | фонарь |
| `M` | карта |
| `Esc` | пауза |

Для лучшего эффекта используйте наушники и полноэкранный режим.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`.

## Проверка production-сборки

```bash
npm run build
npm run preview
```

Готовые файлы окажутся в папке `dist/`, предпросмотр — на `http://localhost:4173`.

## Публикация через GitHub Pages

1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите в него содержимое этой папки и сделайте push в ветку `main`.
3. Откройте **Settings → Pages**.
4. В пункте **Build and deployment → Source** выберите **GitHub Actions**.
5. Откройте вкладку **Actions** и дождитесь успешного workflow `Build and deploy to GitHub Pages`.
6. Ссылка на игру появится в результате шага `deploy` и в настройках Pages.

Workflow уже находится в `.github/workflows/deploy-pages.yml`.

## Технические особенности

Игра написана на Canvas 2D и использует raycasting. Все визуальные эффекты и звук создаются программно, поэтому у проекта нет внешних ассетов, CDN-зависимостей или обязательных npm-пакетов. Это делает сборку устойчивой и удобной для GitHub Pages.

Проекции проверяют поле зрения и прямую видимость до игрока. Когда фигура находится за пределами взгляда, она плавно сокращает дистанцию до своей «зоны комфорта». При прямом взгляде её позиция замораживается.

## Ограничения прототипа

- рассчитан прежде всего на настольный браузер с клавиатурой и мышью;
- это художественный вертикальный срез, а не полноценная производственная версия на Unreal Engine 5;
- озвучка заменена субтитрами и процедурным звуковым оформлением;
- модели и окружение стилизованы средствами Canvas.
